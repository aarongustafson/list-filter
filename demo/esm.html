esm.sh CDN sanity check

This page loads the component class from esm.sh and registers it manually.

Import and register the class

<script type="module">
  import { ListFilterElement } from
    'https://esm.sh/@aarongustafson/list-filter@0.0.1/list-filter.js?bundle&target=es2022';

  if (!customElements.get('list-filter')) {
    customElements.define('list-filter', ListFilterElement);
  }
</script>

<list-filter>
  <p>Replace this markup once you customize list-filter.</p>
</list-filter>
